# 홈 콘텐츠 운영 명세

홈의 기존 2열 레이아웃과 카드 수는 유지한다.

1. 상단 배너: 운영 공지·이벤트. 데이터가 없으면 `최애를 기록하고 취향을 나누는 새로운 공간` 템플릿을 표시한다.
2. 추천 순위 5개: 조회수 인기순. `#분류1 #분류2` 다음 줄에 제목, 그 아래 조회·좋아요·댓글 수.
3. 카테고리 탭: 전체, 애니메이션, 게임, 버튜버, 웹툰·캐릭터.
4. `지금 팬들이 찾는 굿즈`: 공개 `SELLING` 마켓 상품을 좋아요 수, 최신 등록일, ID 순으로 정렬한 상위 5개.
5. `최애 이야기를 나눠요`: 최신 커뮤니티 게시글.
6. 우측: 관심 분야 크리에이터, 지금 주목받는 이야기, 커뮤니티 이용 Tip, 인기 굿즈 둘러보기.

첫 번째 FOCUS 상품 카드는 `#상품태그1 #상품태그2 → 상품명 → 설명 → 카테고리·상태 → 포인트 가격 → 판매자·좋아요 수` 순서로 표시한다. 태그는 `market_items.tags`만 사용하고 이미지는 카테고리를 적은 컬러 플레이스홀더로 유지한다. 실제 상품이 5개보다 적거나 홈 요청이 실패하면 가격·상태·판매자·좋아요 수가 있는 샘플 마켓 상품으로 부족한 슬롯만 채운다.

두 번째 FOCUS와 다른 게시글 영역은 기존 샘플 게시글 fallback을 유지한다. 게시글 분류는 최대 5개지만 홈에서는 앞의 2개만 표시한다.
